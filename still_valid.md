# still_valid.md

Audit trail for issues that were **verified and deliberately left open** — the
counterpart to `deduplication.md` (which records *close* actions). An entry here
means: "I reproduced / investigated this and it is a genuine, live issue (or
otherwise should not be closed)." Append one row per decision; never overwrite.

Before re-verifying an old issue, check here first so you don't redo work already
done. If an issue listed here later gets closed, move/annotate it in
`deduplication.md` at that point.
